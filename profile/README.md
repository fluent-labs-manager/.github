# LabFlow — Платформа управления лабораторными работами
 
> Открытая платформа для проведения, сдачи и проверки лабораторных работ в высших учебных заведениях.
 
---
 
## О проекте
 
**LabFlow** — это веб-платформа, разработанная для автоматизации процесса выполнения и проверки лабораторных работ студентами и преподавателями. Платформа проектировалась с акцентом на простоту внедрения в существующую IT-инфраструктуру ВУЗа и интеграцию с внешними учебными системами.
 
---
 
## 🎯 Ключевые возможности
 
### Для преподавателя
- Личный кабинет с автоматической загрузкой групп и студентов на текущий семестр
- Просмотр прогресса каждого студента по лабораторным работам
- Назначение вариантов заданий студентам на странице группы
- Управление очередью студентов на защиту во время пары
- Проведение устных и заочных защит с возможностью задавать теоретические и практические вопросы
- Контроль честности при заочной защите: мониторинг активной вкладки студента
### Для студента
- Личный кабинет с отображением варианта и задания
- Загрузка решения лабораторной работы прямо в платформе
- Прохождение этапа **предзащиты**: автоматически сгенерированные вопросы по содержанию работы
- После успешной предзащиты — автоматическое добавление в очередь на ближайшую пару
- Участие в заочных защитах по ссылке на конференцию

```
Преподаватель                          Студент
     │                                    │
     ▼                                    │
Видит группы и студентов                  │
на текущий семестр                        │
     │                                    │
     ▼                                    │
Назначает варианты заданий ──────────────▶ Студент видит вариант
                                          и задание (через внешний API)
                                               │
                                               ▼
                                        Загружает решение
                                               │
                                               ▼
                                        Проходит предзащиту
                                        (авто-вопросы по работе)
                                               │
                              ┌────────────────┘
                              ▼
                     Добавляется в очередь
                     на ближайшую пару
                              │
     ┌────────────────────────┘
     ▼
Преподаватель видит очередь
и вызывает студентов
     │
     ├──▶ Очная защита (на паре)
     │
     └──▶ Заочная защита
          (по ссылке на конференцию,
           тесты, лайфкодинг,
           мониторинг вкладки)
```

## 🔗 Интеграции
 
| Система | Описание |
|---|---|
| **Внешний API заданий** | Получение условий задач по варианту студента |
| **ITMO ID** | Синхронизация групп и состава студентов на семестр |
| **Конференц-сервисы** | Поддержка внешних ссылок на видеоконференции (Zoom, Teams, и др.) |
